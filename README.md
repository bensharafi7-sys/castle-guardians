# שומרי המבצר

משחק הגנת מבצר בתלת־ממד לטלפון ולמחשב. אוספים זהב, בונים מגדלים וחומות, ומובילים צבא של קשתים ואבירים מול גלים של אויבים.

- 4 גיבורים עם יכולות מיוחדות
- 4 ארצות עם מצביא בסוף כל אחת
- אפשר להתקין כאפליקציה (PWA) ולשחק גם בלי אינטרנט
