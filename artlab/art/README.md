# מסלול אמנותי חדש: Semi-Realistic

`artlab/index.html` היא סצנה נפרדת מהמשחק: לוחם אחד, אויב אחד ואזור אחד. היא קוראת את כל הנכסים מ־`art/manifest.json`. כשמוסיפים קובץ ורושמים אותו במניפסט, הוא נכנס לסצנה בלי לשנות קוד.

## מה כבר מוכן
- **לוחם:** Dwarf Warrior מאת Northcliffe (CC BY 4.0), כ־12,400 משולשים, עם חומרי PBR מלאים כולל מפת בליטות. אנימציות: Idle, Attack.
- **תאורת סביבה:** HDRI בשם Noon Grass מ־Poly Haven (CC0).
- **מנועים:** טוען GLB, glTF, glTF מוטמע ו־FBX; קרקע עם תבליט אמיתי (גבעות, שיפועים ודרך חצובה); מערבב של 3 שכבות PBR לפי שיפוע ודרך; דשא צפוף שמתנופף ברוח; צללים רכים.

## מה חסר: בדיוק מה שצריך להשיג
| משבצת | מה צריך | מפרט |
|---|---|---|
| אויב | דמות Semi-Realistic עם שלד (Rig) | אנימציות Idle, Run, Attack, Hit, Death; עד 15 אלף משולשים; Atlas אחד בגודל 1024 עד 2048; קובץ GLB או FBX |
| אנימציות ללוחם | Run/Walk, Hit, Death | לשלד של הגמד (שמות עצמות: Hips, UpLeg.L, Arm.R…) |
| קרקע: דשא | סט PBR שחוזר על עצמו בלי תפרים | Albedo, Normal, Roughness ברזולוציית 1K עד 2K |
| קרקע: עפר/דרך | כנ"ל | כנ"ל |
| קרקע: סלע | כנ"ל | כנ"ל |
| סלעים | 2–3 מודלים סרוקים | עד 5 אלף משולשים כל אחד |
| עצים ושיחים | 2–3 מודלים | עד 10 אלף משולשים, עלווה עם Alpha |
| מבנה | מגדל, חומה או בית אחד | עד 15 אלף משולשים |

**מקורות מתאימים לשימוש מסחרי:** Fab/Megascans (חינמיים מנובמבר 2026), Poly Haven (CC0), ambientCG (CC0), חבילות בתשלום כמו Synty, או דמויות מ־Mixamo עם חשבון Adobe שלך. את האתרים האלה אני לא מצליח להוריד מסביבת העבודה שלי. מורידים אותם אצלך ומעלים לכאן, ואני ממיר, מקטין ומחבר.

## איך רושמים במניפסט
```json
"enemy": { "file": "orc.glb", "license": "CC BY 4.0 — Orc by X", "height": 1.9, "anims": { "idle": "Idle", "attack": "Attack" } },
"terrain": { "grass": { "albedo": "grass_albedo.jpg", "normal": "grass_normal.jpg", "license": "CC0 — Poly Haven" } }
```
משבצת בלי קובץ מסומנת בדוח הנכסים (הכפתור "דוח נכסים") ב־✗, עם הסבר.
